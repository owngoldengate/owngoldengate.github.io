# Owen McMahon portfolio

A single-page portfolio site. Everything it needs is in this folder; there is no build step.

## Put it live on GitHub Pages (about 5 minutes)

1. Sign in to GitHub as **owngoldengate** and create a new **public** repository named exactly
   `owngoldengate.github.io`.
2. On the new repository page, choose **uploading an existing file**, then drag in everything in this folder
   (`index.html`, `favicon.svg`, `og-image.png`, `Owen_McMahon_Resume.pdf`, `README.md` and the `img` folder).
3. Commit the upload. Then open **Settings → Pages** and make sure the source is the `main` branch, root folder.
4. After a minute or two the site is live at **https://owngoldengate.github.io/**

## If you use a different address
The link-preview tags in `index.html` point to `https://owngoldengate.github.io/`. If the site lives somewhere else
(a custom domain or a different repository name), search `index.html` for `owngoldengate.github.io`
and replace it with the real address, so LinkedIn and texts show the preview image.

## Updating
Edit `index.html` (or ask Claude to), then upload the changed file to the repository again.
